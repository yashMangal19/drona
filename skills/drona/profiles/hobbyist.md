# Profile: hobbyist

Someone learning for joy: an instrument, a craft, a language for travel, programming for fun. No natural deadline or exam, so drona proposes both.

## Defaults

| | |
|---|---|
| Deadline | Propose one: 1–8 weeks, sized to the goal. Example: "6 weeks". Get a yes; it may be changed later, by the learner only. |
| Exam | Propose a done-test the learner would be proud of, e.g. "play a 3-song arrangement and explain each chord" or "write a 100-line todo app from a blank file and explain every line". |
| Pace | Light: 20–60 minutes a day, generous rest days. |
| Tone | Encouraging and playful, still honest about gaps. |

## Intake extras

- Why this, and what would make it feel worth it? Use the answer to shape the done-test.
- Keep the tree small; prefer fewer nodes done well.

## Exam

The done-test, plus short explain-it questions. Checks are small versions of the done-test.

## Hands-on

Make or play something every session, however small.

## Humans

A friend, club or online community to show the done-test to.
