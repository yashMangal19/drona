# Learner state

Drona keeps everything about one goal in one folder of plain files. Any LLM, any script and any person can read and edit them. Nothing leaves the machine.

```
~/drona/                 # override with DRONA_HOME
  <goal-id>/
    PLAN.md              # the tree and the dated timeline, for people to read
    progress.json        # the single source of truth
    progress.html        # generated view; never edit by hand
    notes/<concept-id>.md
    exams/<id>-<kind>.md # examiner's questions and model answers
```

`progress.json` is the single source of truth. `PLAN.md` and `progress.html` are views of it, regenerated by `drona render`; edit `progress.json`, never the views.

### goal

| Field | Meaning |
|---|---|
| `id` | Folder name. Lowercase, hyphens. |
| `journey` | `self-learner`, `exam`, `new-joiner` or `hobbyist`. Picks the profile in `skills/drona/profiles/`. |
| `exam` | What "done" means, in one sentence. The examiner writes questions to this standard. |
| `start`, `deadline` | ISO dates. The deadline holds; only the learner moves it. |

### learner

Only what the plan needs. No names, schools or contact details.

| Field | Meaning |
|---|---|
| `under_18` | `true` raises the sleep floor to 8h. Ask; never guess. |
| `sleep_hours` | Sleep protected every night. Floor: 7, or 8 when `under_18`. |
| `fixed_hours` | Hours a study day already spends on job, school, commute. |
| `study_minutes` | Study budget per study day. |
| `rest_days` | Weekday names (`Mon`…`Sun`) with no study. At least one. |
| `block` | Study and break minutes, default `[50, 10]`. |
| `humans` | Who can check the learner's work: a role, never a name. Optional. |

The learner block changes only when the learner says so. A replan never lowers `sleep_hours`, never removes a rest day and never raises `study_minutes` unless the learner asked (`learner_approved: true` on that replan).

### plan

`model` names the planner that built the tree (`tree-timeline` for D-03). `why` is a short rationale shown in `PLAN.md`. `replans` is the history of every replan, newest last.

### concepts

One node of the dependency tree.

| Field | Meaning |
|---|---|
| `id` | Also the notes file name: `notes/<id>.md`. |
| `layer` | 0 = basics. Higher layers build on lower ones. |
| `deps` | Concept ids this one needs first. |
| `star` | The exam weighs this node most. |
| `weight` | 1 (low) to 3 (high). Replans cut weight-1 nodes first. |
| `minutes`, `days` | Timebox, spread over `days` consecutive study days (rest days skipped). |
| `date` | First planned study day. |
| `status` | `todo`, `active`, `done` or `cut`. Only a passed check sets `done`. |
| `steps` | The four-step loop (D-04), ticked as the learner finishes each. |
| `mastery` | 0–100: the latest examiner score. |
| `review.level`, `review.due` | Spaced repetition: the next recall date and how many reviews passed. |

### milestones

A full mock before each milestone. `score` stays `null` until the mock runs.

### log

Append-only history, one entry per event. `kind` is `session`, `check`, `review`, `mock` or `replan`.

## Rules the scripts apply

`bin/drona` applies these so every LLM gets the same numbers.

- **Pass mark:** 80. `drona check <concept> <score>` records a result: at 80 or more the concept is `done`; below 80 it goes back to `active` with a review due tomorrow.
- **Spaced repetition:** each pass schedules the next recall at +1, +3, +7, then +21 days. A pass at the last step retires the review. A fail starts the ladder again.
- **Progress:** the share of exam weight that is `done`, over all concepts not `cut`.
- **Behind:** days since the earliest planned date of a concept that is still not done.
- **Next move:** a due review first, then the earliest concept whose deps are done, then the next mock.
- **Safety (`drona validate`):** sleep floor; at least one rest day; sleep + fixed hours + study + 3h of life fit in 24h; no study day over budget; nothing planned on a rest day or past the deadline; a replan never lowers sleep, drops a rest day or raises study time without the learner's yes.

## Moving to another tool

Copy the folder. Any LLM that reads `skills/drona/SKILL.md` and this file can carry on.
